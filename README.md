# CineFeedback - Online Feedback Management System (MERN + Python NLP)

Movie review and rating system with sentiment analysis, mismatch detection, admin analytics and reports.
Tech stack (as per synopsis): MongoDB, Express.js, React.js, Node.js + Python (FastAPI + VADER).

## Folders
    backend/             Node + Express API, Mongoose models, JWT auth, reports
    frontend/            React (Vite) app + Recharts
    sentiment-service/   FastAPI + VADER microservice

## Setup (3 terminals)
Prerequisites: Node 18+, Python 3.9+, MongoDB (local) or a MongoDB Atlas connection string.

1. Sentiment service
       cd sentiment-service
       pip install -r requirements.txt
       uvicorn main:app --port 8000

2. Backend  (edit backend/.env first if you use Atlas: set MONGO_URI)
       cd backend
       npm install
       npm run seed      # demo data
       npm run dev

3. Frontend
       cd frontend
       npm install
       npm run dev       # open http://localhost:5173

Logins: admin@cinefeedback.com / admin123 (admin), demo@cinefeedback.com / demo123 (user)

## Synopsis modules -> where they are
| Module | Location |
|---|---|
| User Authentication (JWT, RBAC, bcrypt) | backend/routes/auth.js, middleware/auth.js |
| Movie Catalog | backend/routes/movies.js, frontend Manage Movies, Movies |
| Review & Rating (1-5, edit/delete, likes) | backend/routes/reviews.js, MovieDetail page |
| Sentiment Analysis + mismatch flag | sentiment-service/main.py, backend/utils/sentiment.js |
| Admin Dashboard | frontend Dashboard page, backend/routes/admin.js |
| Report Generation (PDF / Excel) | backend/routes/reports.js |
| Watchlist | backend/routes/watchlist.js |

## Additions (business value)
Aspect insights (acting, story, music, pacing, ending...), smart alerts on negative-review spikes,
plain-English insights, moderation tickets (Open / In progress / Resolved + hide review), landing + pricing page.

## Testing
    cd backend && npm test               # unit tests: aspects, mismatch, rating aggregation, alerts
    cd sentiment-service && python -m unittest test_sentiment.py -v

Demo data is synthetic (generated by backend/seed.js) and should be described as such in the report.
